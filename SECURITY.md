# Security Policy

If you find a vulnerability in CanIScan itself (for example, a crafted config file that makes it execute code or leak data), please **don't open a public issue**. Report it privately through GitHub's **Security → Report a vulnerability** on this repository.

You can expect an acknowledgement within 7 days.

Bypasses of a detection rule (a pattern that should be caught but isn't) are not vulnerabilities. Please open a normal issue or PR for those.
